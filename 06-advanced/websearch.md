# WebSearch 功能

WebSearch 就是让 AI 能上网搜索。听起来简单，但这功能真的很重要。AI 的知识是有截止日期的，过了那个日期的事情它就不知道了。有了 WebSearch，AI 就能获取最新信息。

---

## 为什么需要 WebSearch

AI 虽然很聪明，但它的知识是有限的。

### 知识截止日期

比如 Claude 的知识截止到 2025 年 1 月，2025 年 1 月之后发生的事情它就不知道了。你问它"最新的 React 19 有什么新特性"，它可能答不上来，因为 React 19 是 2025 年 2 月发布的。

有了 WebSearch，AI 可以实时搜索最新信息，然后告诉你答案。

### 实时信息

有些信息是实时变化的，比如：

- 最新的技术文档
- 框架的最新版本
- 最近的新闻和讨论
- 当前的市场行情
- 最新的 bug 修复

这些信息 AI 的训练数据里肯定没有，必须通过 WebSearch 获取。

### 验证信息

有时候 AI 会"胡说八道"，给出错误的信息。通过 WebSearch，AI 可以验证自己的答案是否正确，给出更可靠的回答。

---

## 如何使用 WebSearch

使用 WebSearch 很简单，就是在提示词里明确告诉 AI 去搜索。

### 基本用法

最简单的方式就是直接说"搜索一下"：

```
你：搜索一下 React 19 的新特性

AI：[执行网络搜索]
根据搜索结果，React 19 的主要新特性包括：
1. ...
2. ...
```

### 指定搜索内容

可以更具体地告诉 AI 搜索什么：

```
你：搜索一下 Python 3.12 的官方文档，看看新增了哪些特性

AI：[搜索 Python 官方文档]
根据官方文档，Python 3.12 新增了：
...
```

### 搜索后再操作

可以让 AI 先搜索，然后根据搜索结果做事情：

```
你：搜索一下 FastAPI 的最新版本，然后帮我升级项目的依赖

AI：[搜索 FastAPI 最新版本]
当前最新版本是 0.109.0
[检查项目依赖]
[更新 requirements.txt]
已升级到最新版本
```

### 验证信息

可以让 AI 搜索来验证信息：

```
你：这个库的用法是不是这样的？先搜索一下官方文档确认

AI：[搜索官方文档]
根据官方文档，用法确实是这样的。不过有一点需要注意：...
```

## 搜索技巧

要让 WebSearch 发挥最大作用，需要掌握一些技巧。

### 1. 明确搜索目标

不要只说"搜索一下"，要说清楚搜索什么：

❌ 不好：搜索一下 React
✅ 好：搜索一下 React 19 的新特性和升级指南

### 2. 指定信息来源

可以指定从哪里搜索：

```
搜索一下 Python 官方文档，看看 asyncio 的用法
搜索一下 Stack Overflow 上关于这个错误的讨论
搜索一下 GitHub 上这个库的 Issues
```

### 3. 限定时间范围

对于时效性强的信息，可以限定时间：

```
搜索一下最近一个月关于 AI 编程工具的讨论
搜索一下 2026 年的前端开发趋势
```

### 4. 搜索后总结

让 AI 搜索完后总结关键信息：

```
搜索一下 Next.js 和 Remix 的对比文章，
总结一下它们的主要区别和适用场景
```

### 5. 多次搜索

如果一次搜索不够，可以多次搜索：

```
先搜索一下这个库的官方文档，
然后搜索一下社区的使用经验，
最后搜索一下有没有已知的问题
```

## 注意事项

使用 WebSearch 时有几个要注意的地方。

### 1. 不是所有 AI 都支持

不是所有 AI 工具都有 WebSearch 功能：

- Claude Code：支持，但需要明确要求
- Codex：部分支持
- Gemini：支持，而且搜索能力很强
- Grok：支持，而且是最强的

使用前确认你的 AI 工具是否支持 WebSearch。

### 2. 搜索需要时间

WebSearch 需要时间，会比普通对话慢一些。如果不需要最新信息，就不用搜索。

### 3. 搜索结果可能不准确

搜索到的信息不一定都是对的，AI 会尽量筛选可靠的来源，但还是要自己判断。

### 4. 有些信息搜不到

有些信息可能搜不到，比如：

- 公司内部的文档
- 需要登录才能看的内容
- 付费内容
- 被墙的网站

这种情况下，WebSearch 就帮不上忙了。

### 5. 注意隐私

搜索的内容会被发送到搜索引擎，注意不要搜索敏感信息。

## 最佳实践

### 1. 优先搜索官方文档

官方文档是最可靠的信息来源，优先搜索官方文档。

### 2. 搜索前先想想

不是什么都要搜索，如果 AI 的知识库里有，就不用搜索。只有需要最新信息或者 AI 不确定时才搜索。

### 3. 验证重要信息

对于重要的信息，让 AI 搜索验证一下，确保准确。

### 4. 保存有用的信息

搜索到有用的信息，可以保存下来，下次就不用再搜索了。

### 5. 定期搜索更新

对于经常变化的技术，定期搜索一下，了解最新动态。

## 总结

WebSearch 是个很重要的功能，让 AI 能够获取最新信息。特别是在学习新技术、解决问题、技术选型时，WebSearch 能帮大忙。

**核心要点：**

- WebSearch 让 AI 能获取最新信息
- 使用时要明确搜索目标
- 配合其他功能使用效果更好
- 不是所有 AI 都支持，使用前确认
- 搜索结果要自己判断，不能全信

养成使用 WebSearch 的习惯，特别是在需要最新信息时，主动让 AI 搜索一下。这样能确保你获取的信息是最新、最准确的。
