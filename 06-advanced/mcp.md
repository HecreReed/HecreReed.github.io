# MCP 服务器

MCP（Model Context Protocol）是个好东西，简单说就是给 AI 工具装插件。你想让 Claude Code 或者 Codex 能做更多事情？装个 MCP 服务器就行了。

---

## MCP 是什么

MCP 就是一套协议，让 AI 工具能够调用外部服务。比如你想让 Claude 读取数据库、操作文件系统、调用 API，都可以通过 MCP 实现。

说白了，MCP 就像是给 AI 装了一堆工具箱。原本 AI 只能读写文件、执行命令，装了 MCP 之后，它能做的事情就多了。

### 为什么需要 MCP

AI 工具本身的能力是有限的。比如 Claude Code 虽然能写代码，但它：

- 不能直接读取数据库
- 不能调用第三方 API
- 不能访问某些特殊的服务
- 不能操作一些专业工具

MCP 就是来解决这些问题的。通过 MCP 服务器，AI 可以调用各种外部服务，能力就大大增强了。

### MCP 怎么工作

工作流程很简单：

1. 你在配置文件里添加 MCP 服务器
2. 启动 Claude Code 或 Codex 时，它会自动连接这些服务器
3. 当 AI 需要某个功能时，就调用对应的 MCP 服务器
4. MCP 服务器执行任务，把结果返回给 AI
5. AI 拿到结果继续工作

整个过程对你来说是透明的，你只需要配置好，剩下的 AI 会自己处理。

## 常用 MCP 服务器

市面上已经有很多现成的 MCP 服务器了，直接拿来用就行。

### 文件系统 MCP

这个最基础，让 AI 能够更好地操作文件系统。虽然 AI 本身就能读写文件，但通过 MCP 可以做得更精细，比如监控文件变化、批量处理文件等。

**适合场景：**
- 需要监控文件变化
- 批量处理大量文件
- 需要更精细的文件操作权限

### 数据库 MCP

这个很实用，让 AI 能直接读写数据库。支持 PostgreSQL、MySQL、SQLite 等常见数据库。

**适合场景：**
- 需要查询数据库生成报表
- 根据数据库内容生成代码
- 数据库迁移和维护

**使用示例：**

你可以直接跟 AI 说："查一下数据库里最近一周的订单数据，生成一个销售报表"。AI 会自动连接数据库，执行查询，然后生成报表。

### GitHub MCP

让 AI 能够操作 GitHub，包括创建 Issue、PR、查看代码、管理仓库等。

**适合场景：**
- 自动化 GitHub 工作流
- 批量处理 Issue 和 PR
- 代码审查和管理

**使用示例：**

"帮我看看这个仓库最近的 Issue，把标记为 bug 的都列出来，然后创建一个 PR 修复最严重的那个"。

### Slack/Discord MCP

让 AI 能够发送消息到 Slack 或 Discord。

**适合场景：**
- 自动化通知
- 团队协作
- 监控和报警

**使用示例：**

"代码部署完成后，发个消息到 Slack 的 #dev 频道"。

### Google Drive MCP

让 AI 能够读写 Google Drive 上的文件。

**适合场景：**
- 处理云端文档
- 团队协作
- 自动化文档生成

### Notion MCP

让 AI 能够操作 Notion 数据库和页面。

**适合场景：**
- 自动化笔记整理
- 项目管理
- 知识库维护

### Godot MCP

这个比较专业，让 AI 能够操作 Godot 游戏引擎。如果你在做游戏开发，这个很有用。

**适合场景：**
- 游戏开发
- 场景编辑
- 脚本生成

## 如何配置 MCP

配置 MCP 其实很简单，就是在配置文件里加几行。

### Claude Code 配置

Claude Code 的 MCP 配置在 `~/.config/claude/config.json` 文件里。

打开这个文件，找到 `mcpServers` 部分，添加你想要的 MCP 服务器：

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "POSTGRES_CONNECTION_STRING": "postgresql://user:pass@localhost/db"
      }
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "your-github-token"
      }
    }
  }
}
```

配置好之后，重启 Claude Code 就生效了。

### Codex 配置

Codex 的配置类似，也是在配置文件里添加 MCP 服务器。具体路径可能不同，但格式差不多。

### 环境变量

有些 MCP 服务器需要环境变量，比如数据库连接字符串、API Token 等。记得在配置里加上，不然服务器启动不了。

**注意安全：**

配置文件里可能包含敏感信息（数据库密码、API Token 等），千万别提交到 Git 仓库。可以用环境变量或者单独的配置文件来管理这些敏感信息。

## 实际应用场景

MCP 的应用场景非常广泛，这里举几个实际例子。

### 场景 1：自动化数据报表

你每天都要从数据库里查数据，生成报表，很烦。有了数据库 MCP，直接跟 AI 说：

"每天早上 9 点，从数据库查询昨天的销售数据，生成一个 Excel 报表，发到我邮箱"。

AI 会自动执行，你啥都不用管。

### 场景 2：GitHub 自动化

你维护一个开源项目，每天都有很多 Issue 和 PR 要处理。有了 GitHub MCP：

"帮我看看最近的 Issue，把重复的合并，把明显是 spam 的关闭，把需要更多信息的打上标签"。

AI 会自动处理，节省大量时间。

### 场景 3：团队协作

你在做一个项目，需要跟团队保持同步。有了 Slack MCP：

"代码有更新时，自动发消息到 Slack。如果测试失败，@相关的人"。

团队成员能第一时间知道项目进展。

### 场景 4：文档自动化

你需要维护项目文档，但经常忘记更新。有了 Notion MCP：

"代码有重大改动时，自动更新 Notion 上的技术文档"。

文档永远是最新的，不用手动维护。

### 场景 5：游戏开发

你在用 Godot 做游戏，需要创建很多场景和脚本。有了 Godot MCP：

"创建一个新的敌人角色，包含移动、攻击、受伤的逻辑，然后生成对应的场景文件"。

AI 会自动在 Godot 里创建好一切。

## 自己写 MCP 服务器

如果现有的 MCP 服务器不能满足需求，你也可以自己写一个。

### 什么时候需要自己写

- 需要调用公司内部的 API
- 需要操作特殊的工具或服务
- 有特殊的业务逻辑需要封装

### 怎么写

MCP 服务器本质上就是一个程序，遵循 MCP 协议就行。可以用 Python、JavaScript、Go 等任何语言写。

官方提供了 SDK，用起来很简单。基本流程：

1. 安装 MCP SDK
2. 定义你的工具（Tool）
3. 实现工具的逻辑
4. 启动服务器

具体怎么写，可以参考官方文档和示例。不过对于大多数人来说，用现成的 MCP 服务器就够了。

## 使用技巧

### 1. 按需配置

不要一次性配置太多 MCP 服务器。只配置你真正需要的，不然启动会变慢，而且容易出问题。

### 2. 测试连接

配置好 MCP 服务器后，先测试一下能不能正常连接。可以让 AI 执行一个简单的操作，看看是否正常。

### 3. 查看日志

如果 MCP 服务器出问题，查看日志是最快的排查方法。日志会告诉你哪里出错了。

### 4. 权限控制

有些 MCP 服务器权限很大（比如数据库 MCP），要注意安全。不要给 AI 过大的权限，只给它需要的最小权限。

### 5. 定期更新

MCP 服务器也会更新，定期检查一下有没有新版本，新版本通常会修复 bug 和添加新功能。

## 常见问题

### MCP 服务器启动失败怎么办？

检查几个地方：

1. 配置文件格式是否正确（JSON 格式很严格）
2. 环境变量是否设置正确
3. 依赖是否安装（比如 npx 命令是否可用）
4. 查看错误日志，看具体报什么错

### MCP 会不会很慢？

一般不会。MCP 服务器都是本地运行或者快速响应的服务，不会明显影响速度。如果觉得慢，可能是某个 MCP 服务器有问题，可以暂时禁用它。

### 安全吗？

只要你配置的 MCP 服务器是可信的，就没问题。不要随便安装来路不明的 MCP 服务器，可能有安全风险。

官方提供的 MCP 服务器都是开源的，可以放心使用。

## 总结

MCP 是个很强大的功能，能大大扩展 AI 工具的能力。配置起来也不复杂，花点时间设置好，后面能省很多事。

**核心要点：**

- MCP 让 AI 能调用外部服务
- 有很多现成的 MCP 服务器可以直接用
- 配置很简单，在配置文件里加几行就行
- 注意安全，不要泄露敏感信息
- 按需配置，不要贪多

如果你经常需要 AI 做一些特定的任务（比如操作数据库、调用 API），强烈建议配置对应的 MCP 服务器。一次配置，终身受益。
