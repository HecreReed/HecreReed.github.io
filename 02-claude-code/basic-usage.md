# Claude Code 基础使用

完成安装和配置后，就可以开始使用 Claude Code 了。本章将介绍如何启动 Claude Code、基本的交互方式，以及一些需要注意的安全事项。

---

## 启动 Claude Code

Claude Code 的启动方式很简单，直接在项目目录中运行 `claude` 命令即可。

### 在当前目录启动

```bash
# 进入你的项目目录
cd /path/to/your/project

# 启动 Claude Code
claude
```

当你在某个目录中启动 Claude Code 时，它默认会在这个目录范围内工作。这意味着它能读取和修改这个目录下的所有文件，但不会随意访问目录外的内容。这种设计既保证了工作效率，又提供了一定的安全边界。

### 全量访问模式

如果你需要 Claude Code 访问整个文件系统，可以在启动时指定更高层级的目录，甚至是根目录：

```bash
# 在用户主目录启动，可以访问所有用户文件
cd ~
claude

# 或者直接指定工作目录
claude --directory /path/to/workspace
```

不过要注意，给予 Claude Code 更大的访问权限意味着它能看到和修改更多文件。虽然 Claude Code 不会主动破坏你的系统，但在处理敏感项目时，还是建议限制它的工作范围。

### 自动执行模式

默认情况下，Claude Code 在执行某些操作时会先征求你的同意。比如要修改文件、运行命令、安装依赖时，它会先告诉你它打算做什么，等你确认后才会执行。

这种交互式的确认机制很安全，但如果你完全信任 Claude Code，或者想让它自动完成整个工作流程，可以使用自动执行模式：

```bash
# 启动自动执行模式
claude --auto-approve

# 或者使用简写
claude -y

# 完全跳过权限检查（危险，仅在完全信任的环境使用）
claude --bypass
# 或者
claude --dangerously-skip-permissions
```

在自动执行模式下，Claude Code 会直接执行所有操作，不再逐个询问。这能大幅提高效率，特别是在处理需要多次修改的复杂任务时。

`--bypass` 参数会完全跳过权限检查系统，让 Claude Code 拥有最大的自由度。这在处理大型项目或需要频繁操作时非常方便，但也意味着 Claude Code 可以不受限制地修改任何文件、执行任何命令。只在你完全信任的项目和环境中使用这个参数。

## 基本交互方式

Claude Code 的使用方式非常直观——就像和一个真实的开发者对话一样。你用自然语言描述你想做什么，它会理解你的意图并执行相应的操作。

### 简单的文件修改

最基础的用法就是让 Claude Code 帮你修改代码：

```
你：帮我在 index.js 中添加一个函数，用于计算两个数的和

Claude Code：好的，我来添加这个函数。
[读取 index.js]
[在文件中添加函数]
已完成！我在 index.js 中添加了 add 函数。
```

整个过程中，Claude Code 会自动读取文件、理解现有代码结构、在合适的位置添加新代码、保持代码风格一致。你不需要告诉它具体在哪一行添加，它会自己判断。

### 多文件协同修改

Claude Code 能够同时处理多个文件的修改，并保持它们之间的一致性：

```
你：我想给用户模块添加一个邮箱验证功能

Claude Code：好的，我需要修改以下文件：
- models/user.js：添加 email 字段和验证规则
- controllers/user.js：添加邮箱验证逻辑
- routes/user.js：添加验证接口
- tests/user.test.js：添加测试用例

开始执行...
[依次修改各个文件]
完成！邮箱验证功能已添加，所有相关文件都已更新。
```

它会自动识别哪些文件需要修改，并确保所有改动相互配合，不会出现某个文件改了但另一个文件忘记改的情况。

### 运行和测试

Claude Code 不仅能写代码，还能运行代码、执行测试、查看结果：

```
你：运行一下测试，看看有没有问题

Claude Code：好的，运行测试...
[执行 npm test]
发现 2 个测试失败：
- user.test.js: 邮箱格式验证测试失败
- user.test.js: 空邮箱测试失败

我来修复这些问题...
[修改代码]
[重新运行测试]
所有测试通过！
```

它会根据测试结果自动调整代码，直到所有测试通过。这种"写代码-测试-修复-再测试"的循环是完全自动化的。

### 代码审查和优化

你也可以让 Claude Code 审查现有代码，提出改进建议：

```
你：看看 utils.js 有没有可以优化的地方

Claude Code：我检查了 utils.js，发现几个可以改进的地方：
1. formatDate 函数可以使用更简洁的写法
2. 有几个重复的字符串处理逻辑可以提取成公共函数
3. 缺少错误处理

需要我帮你优化吗？

你：好的，优化一下

Claude Code：[开始优化代码]
完成！代码已优化，可读性和健壮性都有提升。
```

## 持续对话

Claude Code 会记住你们之前的对话内容，所以你可以进行连续的交互，而不需要每次都重新解释背景：

```
你：帮我添加一个用户登录功能

Claude Code：[实现登录功能]
完成！

你：再加一个记住密码的选项

Claude Code：好的，我在刚才的登录功能基础上添加"记住密码"选项。
[修改相关代码]
完成！

你：测试一下

Claude Code：[运行测试]
测试通过！
```

这种连续对话的能力让你可以逐步完善功能，而不是一次性把所有需求都说清楚。

## 安全注意事项

虽然 Claude Code 非常强大，但在使用时还是需要注意一些安全问题。

### 敏感信息处理

Claude Code 对隐私保护的态度相对宽松。如果你不小心把密码、API Key 或其他敏感信息暴露给它，它会警告你这是不安全的，建议你立即修改。但即便如此，它还是会继续帮你完成任务。

```
你：帮我连接数据库，密码是 MyPassword123

Claude Code：⚠️ 警告：你在对话中暴露了密码！
这是非常不安全的做法，建议你：
1. 立即修改这个密码
2. 使用环境变量存储敏感信息
3. 不要在代码或对话中硬编码密码

不过我会继续帮你完成数据库连接...
[继续执行任务]
```

这和 Codex 的处理方式不同。Codex 在检测到敏感信息时会直接拒绝继续工作，强制你先解决安全问题。Claude Code 更像是一个提醒你但不强制你的助手。

所以使用 Claude Code 时，你需要自己更加注意安全：
- 永远不要在对话中直接输入密码、密钥
- 使用环境变量或配置文件存储敏感信息
- 定期检查代码，确保没有硬编码的敏感数据
- 如果不小心泄露了，立即修改密码

### 代码审查

虽然 Claude Code 生成的代码质量通常很高，但它毕竟是 AI，可能会犯错。建议你：

- 在自动执行模式下工作后，仔细检查所有改动
- 运行完整的测试套件，确保没有破坏现有功能
- 使用 Git 查看具体改了什么：`git diff`
- 对于关键功能，最好人工审查一遍代码逻辑

### 权限控制

如果你在团队项目中使用 Claude Code，要注意：

- 不要在生产环境直接运行 Claude Code
- 限制 Claude Code 的工作目录，避免误改其他项目
- 重要操作前先备份或创建 Git 分支
- 使用 `--auto-approve` 时要特别小心

## 实用技巧

### 明确的指令

虽然 Claude Code 能理解自然语言，但越明确的指令效果越好：

**不够明确：**
```
你：改一下登录功能
```

**更明确：**
```
你：在登录功能中添加邮箱验证，要求邮箱格式正确且不能为空
```

### 借助其他 AI 生成提示词

如果你对某个需求的描述不够清晰，或者不知道如何准确表达，可以先去问 ChatGPT 或其他 AI，让它帮你生成一个精准的提示词。

比如你想让 Claude Code 做一个复杂的功能，但不知道怎么说清楚，可以这样问 ChatGPT：

```
我需要 Claude Code 帮我做一个用户认证系统，包括注册、登录、密码重置等功能。
请你帮我生成一个能直接喂给 Claude Code 的超级提示词，非常准确非常牛逼的，给我 markdown 代码块。
```

ChatGPT 会帮你生成一个详细、结构化的提示词，包含所有必要的技术细节、实现要求、边界条件等。然后你直接把这个提示词复制粘贴给 Claude Code，它就能准确理解你的需求并开始工作。

这种方法特别适合：
- 复杂的架构设计任务
- 需要考虑多种边界情况的功能
- 涉及多个技术栈的集成工作
- 你不太熟悉的技术领域

通过这种"AI 帮 AI"的方式，可以大幅提高需求传达的准确性，减少来回沟通的次数。

### 分步执行

对于复杂任务，可以分步骤让 Claude Code 执行：

```
你：我想重构用户模块，先帮我分析一下现有代码结构

Claude Code：[分析代码]
当前结构是...建议重构方案是...

你：好的，先重构 model 层

Claude Code：[重构 model]
完成！

你：现在重构 controller 层

Claude Code：[重构 controller]
完成！
```

### 利用上下文

Claude Code 能记住对话历史，充分利用这一点：

```
你：帮我实现一个购物车功能

Claude Code：[实现购物车]
完成！

你：用同样的风格实现一个收藏夹功能

Claude Code：好的，我会参考刚才购物车的实现风格。
[实现收藏夹]
完成！
```

### 请求解释

如果不理解 Claude Code 做了什么，可以直接问：

```
你：你刚才为什么要修改 config.js？

Claude Code：因为新的邮箱验证功能需要配置 SMTP 服务器信息，
所以我在 config.js 中添加了邮件相关的配置项。
```

## 退出和重启

### 退出 Claude Code

```bash
# 在对话中输入
exit

# 或者按快捷键
Ctrl+C
```

### 查看历史记录

Claude Code 会保存对话历史，下次启动时可以继续之前的工作：

```bash
# 查看历史会话
claude history

# 恢复之前的会话
claude resume <session-id>
```

## 常用命令

在 Claude Code 对话中，除了自然语言，还可以使用一些特殊命令：

```bash
# 查看帮助
/help

# 清空对话历史
/clear

# 查看当前工作目录
/pwd

# 切换工作目录
/cd /path/to/directory

# 查看文件列表
/ls

# 撤销上一次操作
/undo

# 查看改动
/diff
```
