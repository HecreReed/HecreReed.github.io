# AI Agent 与 AI 使用指南

全面的 AI Agent 使用教程，涵盖 Claude Code、Codex、Gemini、Grok 四大主流工具。

## 🌐 在线访问

**网站地址**：https://HecreReed.github.io

## 📖 关于本项目

这是一份完整的 AI Agent 使用指南，旨在帮助开发者全面掌握主流 AI 编程工具的使用方法。

### 涵盖内容

- **Claude Code** - Anthropic 官方 CLI 工具
- **Codex / GitHub Copilot** - OpenAI 的代码生成工具
- **Gemini** - Google 的多模态 AI 模型
- **Grok** - xAI 的实时 AI 助手

## ✍️ 编写内容

### 快速开始

1. 阅读 [文档编写指南](_docs/writing-guide.md)
2. 在对应章节目录下创建 Markdown 文件
3. 添加 Front Matter 和内容
4. 本地预览后提交

### Front Matter 格式

```yaml
---
layout: default
title: 页面标题
---
```

### 文件命名规范

- 使用小写字母和短横线：`what-is-ai-agent.md`
- 放在对应的章节目录下
- 在章节的 `index.md` 中添加链接

## 🛠️ 本地开发

### 安装依赖

```bash
bundle install
```

### 启动本地服务器

```bash
bundle exec jekyll serve
```

然后访问 http://localhost:4000

### 实时预览

修改文件后，浏览器会自动刷新显示最新内容。
